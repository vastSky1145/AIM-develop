### 功能演示

#### 1. 上传PPT

1. 点击A区的"上传PPT"按钮
2. 选择.ppt或.pptx文件
3. 等待解析完成
4. 论文出现在A区列表中

#### 2. 查看论文

1. 在A区点击任意论文
2. B区显示论文的树形结构
3. C区显示论文大纲

#### 3. 编辑节点

1. 在B区右键点击任意节点
2. 选择"编辑"
3. 弹出编辑对话框
4. 填写内容，点击"生成"使用AI
5. 点击"保存"保存修改

#### 4. 使用知识库

1. 点击A区的"提交知识"按钮
2. 跳转到知识库管理页面
3. 上传PDF文件到知识库
4. 使用搜索框检索知识
5. 点击"返回主页"回到主界面

## ⚠️ 常见问题

### 1. npm install 失败

```bash
# 清除缓存后重试
npm cache clean --force
npm install
```

### 2. 后端连接失败

检查：
- 后端是否正常运行在 http://localhost:8000
- MongoDB是否启动
- 浏览器控制台是否有CORS错误

### 3. 登录失败

确认：
- 后端app.py正常运行
- MongoDB中有对应的用户数据
- 网络请求正常（F12查看Network）

### 4. PPT上传无响应

检查：
- 文件格式是否正确（.ppt/.pptx）
- PowerPoint是否安装（Windows）
- 后端日志是否有错误信息

### Nginx配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    root /path/to/dist;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location /api/ {
        proxy_pass http://localhost:8000/api/;
    }
}
```
